隐私政策

更新日期：2026年9月22日  |  生效日期：2026年9月22日

欢迎使用 Space Defender 3D（太空守卫者）（以下简称"本游戏"）。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。请您在使用本游戏前，仔细阅读并充分理解本《隐私政策》的全部内容。

一、我们收集的信息

本游戏为纯前端网页游戏，不设置用户注册、登录系统，不收集、不上传、不存储您的任何个人身份信息（包括但不限于姓名、手机号、邮箱、身份证号、地理位置、通讯录、相册等）。

游戏运行过程中产生的所有数据（包括但不限于分数、生命值、关卡进度、难度选择）均仅保存在您当前设备的浏览器内存中，刷新或关闭页面后即被清除，不会发送至任何服务器。

二、本地存储

本游戏不使用 Cookie、localStorage、sessionStorage、IndexedDB 或任何其他形式的浏览器本地持久化存储来记录您的个人信息或游戏数据。所有游戏状态仅存在于当前页面会话的内存中。

三、第三方服务

本游戏通过公共 CDN（内容分发网络）加载以下第三方资源：

  • Three.js（由 jsDelivr CDN 提供）：用于 3D 图形渲染。当您加载游戏页面时，浏览器会向 CDN 服务器请求该 JavaScript 文件，CDN 服务器可能会记录您的 IP 地址和请求日志，具体隐私政策请参阅 jsDelivr 官方网站。

除上述 CDN 资源加载外，本游戏不向任何第三方发送数据，不接入任何广告 SDK、统计分析 SDK、推送 SDK 或社交分享 SDK。

四、音频播放

本游戏包含背景音乐文件（主界面音乐与战斗音乐），这些音频文件随游戏页面一同从您所部署的静态托管服务器（如 GitHub Pages、Cloudflare Pages）加载，不会收集或传输您的任何信息。音频播放需要您在页面上进行首次点击交互后由浏览器自动触发，这是浏览器的自动播放策略要求。

五、触摸与键盘输入

本游戏在运行期间会监听您的键盘按键（WASD、方向键、空格键、P 键）和触摸屏操作（虚拟摇杆、射击按钮），这些输入事件仅在本地用于控制游戏角色，不会被记录、保存或上传。

六、儿童隐私

本游戏为通用娱乐内容，不针对 14 周岁以下的未成年人进行定向设计，也不会故意收集未成年人的个人信息。由于本游戏本身不收集任何个人信息，因此无需获得监护人同意。若监护人发现未成年人在未经同意的情况下使用本游戏，可直接关闭浏览器页面。

七、您的权利

根据适用的数据保护法律法规，您可能享有以下权利：

  • 知情权与访问权：您有权了解我们如何处理您的信息。由于本游戏不收集个人信息，因此无数据可供访问。
  • 删除权：由于我们不存储您的任何数据，您无需请求删除。关闭或刷新浏览器页面即可清除所有临时游戏状态。
  • 撤回同意权：您可以随时通过关闭页面停止使用本游戏，即视为撤回同意。
  • 拒绝权：若您不同意本隐私政策，请点击"不同意"按钮或关闭页面，此时将无法进入游戏。

八、信息安全

本游戏为纯静态网页应用，所有代码和资源文件均通过 HTTPS 协议传输（取决于您的部署方式），不包含后端服务器、数据库或用户账号系统，因此不存在数据泄露、数据库被入侵等风险。建议您通过官方或可信的托管平台访问本游戏。

九、跨境数据传输

本游戏本身不进行任何数据传输。若您通过 GitHub Pages 或 Cloudflare Pages 等海外平台访问，CDN 资源请求可能涉及跨境网络访问，这属于浏览器与 CDN 之间的标准网络通信，不涉及您的个人信息上传。

十、隐私政策的更新

我们可能会适时修订本隐私政策。当政策发生重大变更时，我们会在游戏启动页面重新展示本政策并要求您确认。您继续使用本游戏即表示同意受修订后的隐私政策约束。

十一、联系我们

如果您对本隐私政策有任何疑问、意见或建议，可通过以下方式联系：

  • 请在游戏部署所在的 GitHub 仓库提交 Issue；或
  • 联系游戏部署者（即向您提供本游戏访问地址的个人或组织）。

本游戏为开源/免费娱乐项目，不涉及任何商业数据收集行为。
